# bluey-parenting · 布鲁伊父母支持

基于动画片《布鲁伊》（*Bluey*）与经典心理学框架的育儿支持技能（`SKILL.md`）。

当你在带娃时快要撑不住、搞不懂孩子的行为，或者只是做饭前急需一个能让孩子自己玩一会儿的点子，它会优先从班迪特（Bandit）和奇莉（Chilli）的日常应对里找参考；没有直接对应的剧集时，再补充有明确出处的心理学视角。

班迪特和奇莉也不是完美父母——会累、会敷衍、会发火后后悔，但还在努力。这个技能的语气更像一个过来人在厨房跟你聊天：先接住你的感受，再给一个今晚就能做的小动作。

## 它能做什么

不用组织语言，按当下的状态直接开口就行，技能会自动走不同的回应路径：

| 你当下的状态 | 可能会说的话 | 它怎么回应 |
|---|---|---|
| **正在崩溃（急救型）** | “我快被气死了”“刚才又没忍住吼了孩子” | 不讲道理，先给一个 30 秒能稳住自己的动作；等缓过来，再理清触发点，用班迪特/奇莉也崩过的时刻陪你松绑自责 |
| **搞不懂孩子（困惑型）** | “最近总打人”“为什么每天出门都要拉锯” | 匹配《布鲁伊》里的相似剧集（标明季集号并附 B 站正版链接），拆解剧中的做法为什么有效，给 1 个可借鉴的步骤 |
| **急需点子（灵感型）** | “今天玩什么”“做饭时怎么让 ta 自己玩会儿” | 跳过寒暄共情，直接给准备 ≤ 5 分钟、用家里常见物品就能玩 15 分钟以上的救场游戏 |
| **事后自责（反思型）** | “我总是控制不住脾气”“觉得自己不够好” | 区分“事情本身的难”和“我不该做不好的自责”，温和复盘，不评判、不说教 |

## 设计原则

- **情绪先于方法**：除了纯找游戏点子的场景，先看见父母的处境，再谈策略，不说“你应该”“你怎么不”。
- **剧集优先，心理学补位**：优先从《布鲁伊》三季 150+ 集日常中找具体参照；需要理论补充时，从 P.E.T. 父母效能训练、非暴力沟通、依恋理论、积极教养、John Gottman 情绪辅导、Kristin Neff 自我同情及 HALT 原则中选取，并注明理论与提出者，不用“心理学研究表明”这类模糊说法。
- **按年龄自然适配**：支持提前记录孩子的年龄、性别与数量，后续自动匹配 **1–2 岁**、**3–5 岁**、**6–8 岁**不同阶段的发展特点（不配置也能用，会结合行为特征合理推断并说明）。
- **接得住模糊求助**：哪怕只丢下一句“好累”“又来了”，或只提了做饭、洗澡、出门时的烦躁，也会从生活场景识别信号，先给轻量回应，不追问细节、不强行归因。
- **只留一个小动作**：短句为主，不灌鸡汤；每次回复末尾最多给 1 个今晚就能落地的小尝试。

## 怎么安装

适用于任何支持 `SKILL.md` 规范的 AI 工具或 Agent（也可直接将 `SKILL.md` 作为系统提示词 / 项目指令载入）。纯文本技能，无代码依赖，无需额外配置 API Key。

### 方式一：命令行克隆

将仓库克隆到你所用工具的技能目录中（文件夹建议命名为 `bluey-parenting`，具体路径以对应工具说明为准）：

```bash
git clone https://github.com/mocomeng-666/bluey-parenting-skill.git bluey-parenting
```

### 方式二：下载压缩包

1. 点击本页右上角 **Code → Download ZIP**，下载并解压。
2. 将解压后的文件夹改名为 `bluey-parenting`，放入所用 AI 工具的技能目录，保持以下结构：

```text
bluey-parenting/
├── SKILL.md
└── README.md
```

3. 重新打开会话或刷新技能列表即可生效。

## 怎么使用

开启会话后直接说眼前的事即可；在需要显式调用技能的工具中，可先点名 `bluey-parenting` 或「布鲁伊父母支持」：

> 用 bluey-parenting。我快崩溃了，哄睡哄了一个半小时还不睡，刚才冲孩子发火了。

> 三岁半最近什么都说“不要”，穿鞋出门每天都要僵持半天，怎么办？

> 我要准备晚饭了，给个 5 分钟内能布置好、适合四岁孩子自己玩的游戏。

> 每次看到别的妈妈情绪那么稳定，就觉得自己特别差劲。

如果不想每次重复说孩子多大了，也可以对它说一句 **“记住我家孩子信息”**（记录年龄、性别、几个娃），后续对话会自动按年龄适配建议。

### 按需自定义

核心逻辑、剧集索引与救场游戏表均在单文件 [`SKILL.md`](./SKILL.md) 中，可直接用任意文本编辑器修改：

- 在场景表或游戏表中补充你和孩子常看的剧集、常玩的家常游戏；
- 在心理学补位部分增补你认可的研究者或养育框架（建议保留明确出处）；
- 根据自家孩子的年龄段微调默认沟通风格。

## 使用边界

- **不替代专业支持**：如涉及产后抑郁倾向、严重情绪危机或家庭暴力等情况，请优先寻求专业心理咨询或医疗帮助。
- **不评判育儿选择**：对喂养方式、全职或职场、宽松或严格等不同家庭选择保持中立；剧集角色的做法仅作启发，不是唯一标准答案。
- **安全优先**：5 分钟救场游戏仅推荐利用家中常见、安全物品即可开展的活动。
